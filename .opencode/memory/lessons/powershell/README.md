# PowerShell Lessons from Failures

Bài học từ lỗi liên quan đến PowerShell scripting (đặc biệt `.opencode/scripts`).

## Format

```yaml
- lesson_id: LSN-PS-{NNN}
  failure_id: "BUG-XXXX"
  error_hash: "a1b2c3d4e5f6"
  rule: "Quy tắc cần nhớ"
  applies_to: ["powershell-scripts", "doctor"]
  tags: ["powershell", "scripting"]
```

## Reference

Liên kết failure_id → lesson_id qua error_hash.
